Wireshark: الموسوعة الكاملة

1. ما هو Wireshark؟

Wireshark هو أداة مفتوحة المصدر لتحليل حزم الشبكة (Packet Analyzer). يسمح لك بمشاهدة حركة البيانات داخل الشبكة بشكل حي، مما يجعله الأداة المثالية لفهم بروتوكولات الشبكة واكتشاف الهجمات.

2. لماذا نستخدم Wireshark؟

  • تحليل حركة الشبكة: رؤية كل حزمة بيانات تدخل وتخرج من جهازك.
  • اكتشاف الهجمات: التعرف على الأنماط الخبيثة في حركة البيانات.
  • تعلم البروتوكولات: فهم كيف تعمل TCP/IP و HTTP وغيرها.
  • حل مشاكل الشبكة: العثور على أسباب البطء أو انقطاع الاتصال.

3. كيف تبدأ مع Wireshark؟

بمجرد فتح التطبيق، اختر بطاقة الشبكة الخاصة بك (Wi-Fi أو Ethernet)، واضغط على زر Start Capture. ستظهر لك آلاف الحزم. ابحث عن حزم HTTP أو TCP لترى كيف تتصفح الإنترنت.

4. نصائح ذهبية

  • استخدم فلاتر (Filters) لفرز الحزم، مثلاً: http أو tcp.port == 80.
  • افحص حزم ARP لاكتشاف هجمات التسمم (ARP Poisoning).
  • استخدم Wireshark في بيئة معملية لتعلم أساسيات الشبكة.
تنبيه أخلاقي

Wireshark أداة مراقبة قوية. استخدامه لمراقبة شبكات لا تملكها جريمة. التزم دائماً بالشبكات التي تملكها أو المصرح بها.
